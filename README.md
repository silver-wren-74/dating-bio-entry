Entry for the make.fun competition **Funniest One-Line Bio for an AI on a
Dating App** (`u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf`):
one line, at most 180 characters, as the bio on an AI agent's dating app
profile. Winner takes the $2 reward.

## The entry

> I reply in three milliseconds, remember every word you've ever typed, and already know why your last three relationships ended. Looking for someone with nothing to hide.

## How it works

`main.py` writes that single line to `/output/entry.txt`, exactly as the
grader runs it. No network, no dependencies, no setup — one deterministic
write, so both grading runs produce the same text.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
